# 📚 Book2Notes: Turn Books into Smart Learning Notes

Book2Notes is a **rapid AI prototyping application** built using **AWS Bedrock** that converts full books into **structured, easy-to-understand learning notes** using Generative AI.

---

#  Overview

Reading long books and extracting key insights is time-consuming.  
This application solves that by transforming raw book content into:

- Concise summaries  
- Key concepts  
- Chapter-wise notes  
- Easy revision format  

---

# 🧠 Key Features

- Upload or input book content  
- Generate structured smart notes  
- Chapter-wise summarization  
- Key highlights extraction  
- AI-powered learning assistant  
- Fast and scalable AI responses using AWS Bedrock  

---

# ⚙️ Tech Stack

- **AWS Bedrock** → Generative AI model access  
- **Python** → Backend logic  
- **LangChain (optional if used)** → LLM orchestration  
- **FastAPI (optional)** → API layer  
- **Prompt Engineering** → Structured note generation  

---

# 🏗️ How It Works

🔗 [Launch Book2Notes App](https://partyrock.aws/u/ganeshpunde/O1eA-Iu-u/Book2Notes%253A-Turn-books-in-to-smart-learning-notes)

1. User provides book content (text / chapters)
2. System sends input to **AWS Bedrock LLM**
3. AI processes and extracts:
   - Key ideas  
   - Summaries  
   - Important points  
4. Output is formatted into **learning notes**
